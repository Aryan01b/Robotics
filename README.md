## URDF Models

This repository contains several URDF (Unified Robot Description Format) models for different robotic configurations:

1. **[Ackermann Drive](urdfs/ackermann_drive.urdf.xacro)** - Model for a car-like robot with steering control
2. **[Differential Drive](urdfs/diff_drive.urdf.xacro)** - Standard two-wheeled differential drive robot
3. **[Dogbot](urdfs/dogbot.urdf.xacro)** - Quadruped robot model
4. **[6-DOF Industrial Arm](urdfs/industrial_arm_6dof.urdf.xacro)** - Six-degree-of-freedom robotic arm
5. **[Mecanum Drive](urdfs/mecanum_drive.urdf.xacro)** - Omnidirectional drive using mecanum wheels
6. **[SCARA Robot](urdfs/scara_bot.urdf.xacro)** - Selective Compliance Assembly Robot Arm
7. **[Two-Wheel Drive](urdfs/two_wheel_drive.urdf.xacro)** - Simple two-wheeled robot with caster
